# OMOP DATA QUALITY REPORT

1. Open the **R project** and install the required libraries by running *renv::restore()*. This will install all package versions specified for the project to ensure a reproducible environment.

2. Open the R Markdown file **Report_comparing.Rmd**, set the connection details for both CDM instances (the previous and the new releases). Then generate the report by clicking the “Knit” button in the top toolbar of RStudio, selecting “Knit to HTML”. This will render the R Markdown file and produce an HTML report with the comparison results.
